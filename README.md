# Проект DevTool. Единый источник правды для конфигов системы.

## Идея проекта

**Проблема**: переустановив систему, надо заново подключать все конфиги, ставить нужные пакеты, применять скрипты и так далее....
Проект решает эту проблему тем, что все настройки, конфиг и тд - хранится локально в этой папке, а сама папка - на github с --public режимом.

## Структура

1. alacritty, IDE, nvim, tmux - папки где прямолинейно написан сам конфиг
2. system - все настройки которые делал/делаю в системе, делаются симлинком на содержимое этой папки... Архитектуру и тд надо ещё продумывать.
3. scripts - готовые скрипты для решения конкретных задач

## Папка system

Пока это папка под мою текущую систему:

1. acpi создавался когда работал над яркостью (fn+f8-9)
2. apt - это пакеты, которые установлены для решения конкретных задач.. например, пакеты для того чтобы корректно запустился и работал throne. Всё, что касается настройки самого sway, включая пакеты, конфиг и так далее, хранится именно в system/sway.. архитектуру и тд можно будет продумать сразу либо чуть позже.
